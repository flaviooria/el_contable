# ADR Template

Use this template only when `docs/decisions/` does not already establish a local ADR format.

```markdown
# ADR NNN: <Decision title>

## Status

Proposed

## Context

<Why a decision is needed. Include the constraints and forces that matter.>

## Decision

<State the chosen architectural decision clearly.>

## Alternatives Considered

### <Alternative>

<Why it was not selected.>

## Consequences

### Positive

- <Consequence>

### Negative / Trade-offs

- <Consequence>

## Related

- Work item: `<ID>` or `none`
- OpenSpec change: `<change-id>` or `none`
```

Keep one ADR focused on one coherent architectural decision.
